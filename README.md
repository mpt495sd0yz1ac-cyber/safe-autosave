# Safe Auto Save

このリポジトリには、Pythonを使ってテキストファイルに自動で文字を書き込み、カレントディレクトリに保存するサンプルスクリプトが含まれています。

## スクリプト内容

- `safe_autosave.py` : 「こんにちは！Pythonで自動入力中です。」という文字列を
  カレントディレクトリに `demo.txt` として保存します。
  
## 使い方

1. Python 3 がインストールされている環境で、リポジトリをクローンまたはダウンロードします。
2. ターミナルやコマンドプロンプトで、スクリプトがあるディレクトリに移動します。
3. 以下のコマンドを実行します：
   ```bash
   python safe_autosave.py
